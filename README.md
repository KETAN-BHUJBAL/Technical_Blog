# Technical Blog

Welcome to the **Technical Blog** repository! This is a web-based application built to share, manage, and read technical articles and tutorials.

---

## 🚀 Project Overview

The **Technical Blog** platform is designed to provide a clean and structured space for publishing technical write-ups. It includes backend code and web resources organized following standard Java web application structures.

> *This is my 1st app for JSP/Servlet created for enhancing my learning curve.*

---

## 📂 Project Structure

```text
Technical_Blog/
│
├── .settings/       # IDE configuration settings
├── WebContent/      # Frontend files (JSP, HTML, CSS, JavaScript, assets)
├── build/           # Compiled output files
├── src/             # Source code (Java servlets, classes, controllers, etc.)

🛠️ Tech Stack
Language: Java

Platform/Web: Java Servlets / JSP (Java EE)

Frontend: HTML, CSS, JavaScript

IDE Configuration: Eclipse (.classpath, .project)

⚙️ Getting Started

Prerequisites

Java Development Kit (JDK) installed.

A Java-compatible Servlet Container / Application Server (such as Apache Tomcat).

An IDE like Eclipse IDE for Enterprise Java Developers or IntelliJ IDEA.


Installation & Setup
Clone the Repository:

Bash
git clone [https://github.com/KETAN-BHUJBAL/Technical_Blog.git](https://github.com/KETAN-BHUJBAL/Technical_Blog.git)
Import into your IDE:

Open your IDE (e.g., Eclipse).

Go to File > Import > Existing Projects into Workspace.

Select the cloned Technical_Blog folder.

Configure the Server:Attach your local Apache Tomcat server (or your preferred server) to the project build path.

Run the Project: Right-click the project, select Run As > Run on Server, and choose your Tomcat server instance.
